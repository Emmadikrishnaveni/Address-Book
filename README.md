# Address Book Management System

## Project Overview
The Address Book Management System is a C programming project developed to manage contact information efficiently. It allows users to store, search, edit, delete, and display contact details.

## Features
- Add new contacts
- Search contacts
- Edit existing contact details
- Delete contacts
- Display all saved contacts
- Save contact information in a file

## Technologies Used
- Programming Language: C
- Concepts: Structures, Pointers, File Handling
- Platform: Linux
- Compiler: GCC

## Project Structure
- main.c – Main program
- contact.c – Contact management functions
- contact.h – Header file
- list.txt – Contact data storage
- .gitignore – Files excluded from Git

## Compilation

Compile the project using GCC:

    gcc main.c contact.c -o addressbook

## Execution

    ./addressbook
